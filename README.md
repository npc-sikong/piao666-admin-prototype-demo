## 演示方式

页面继续使用原版组件和交互。原先的数据调用已全部指向浏览器内的演示状态，筛选、保存、状态切换、模拟任务、额度与账本联动、导出均在本地完成。

- 没有 API 服务、数据库、抓取任务或真实发放。
- 静态预览服务器只提供文件，拒绝 `/api/` 请求及所有非 GET/HEAD 请求。
- 页面设置 `connect-src 'none'`，阻断网络数据连接。
- 金额、账号、订单、号码、任务和审计均为虚构演示数据。算法结果用于展现页面流程，不代表原系统的真实计算结果。
- 上传只读取所选文件以演示证据登记。不要使用真实敏感材料。
- CSV/XLSX 由浏览器生成，可下载查看。
- 页面中的“服务端”“正式命令”“账本事实”等文案按原版保留，在此原型中均对应本地模拟状态。

## 当前版本修改（版本号待指定）

- “会员清单”改名为“会员列表”；默认每页 10 条，可选 10/20/40/60/80/100 条。分页提供并排页码、省略号、上一页、下一页、最后一页和“选择第几页”下拉框，选择后立即跳转；筛选、重置、改变每页条数均回到第一页。

- 会员名称下的账号和 ID 副行隐藏；名称及“查看详情”仍进入原会员详情。会员编号、昵称和登录账号仍可搜索。
- 保留“站长扣除积分”及之前的列；之后按要求排列：可用积分、冻结积分、AI分红、已结算净收益、总推广积分、总参与积分、AI总额度、AI使用额度、AI剩余额度、直属会员数、下级总会员、直属会员可用积分、下级会员总可用积分、邀请码；最后保留操作列。
- 可用积分 = 累计充值积分 + 总推广积分 + 净输赢值 + AI合买分红 − 站长扣除积分。“净输赢值”对应“已结算净收益”，“AI合买分红”对应“AI分红”；冻结积分单列展示，不在公式中另行扣减。
- 直属仅第一层，下级包含全部层级且不含本人；人数及可用积分合计使用完整本地推荐关系，不受当前筛选和分页影响。AI剩余额度 = AI总额度 − AI使用额度。
- 列表与详情共用本地统计。模拟 AI 发放更新 AI 分红、普通结算更新净收益，并按公式重算可用积分。已有浏览器数据不清空；缺失的新字段补齐，旧数据中的 AI 发放按可识别的本地流水补入。
- 模块标题与菜单加标识，列表及详情右上角增加“修改说明”；“版本修改说明”汇总内容与模块说明共用一份源数据，无自动版本号。
